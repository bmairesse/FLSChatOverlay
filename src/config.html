FLS Chat Overlay

Leitura anônima do chat. Nenhum login, token ou senha.

Cada perfil tem os seus próprios chats, com posição e aparência próprias. Trocar de perfil troca todos os overlays de uma vez — dá para ter um perfil por jogo, ou um para a live e outro para assistir. Também dá para trocar pela bandeja, sem abrir esta janela.

    Cada chat é uma janela de overlay própria, com o seu canal e a sua configuração. O interruptor da direita mostra e esconde a janela daquele chat na hora, sem precisar selecionar nada. Clicar no nome seleciona o chat — é dele que tratam os ajustes abaixo.

    Chat selecionado

    Só para você se achar aqui — não aparece no overlay.

    Só o nome que aparece na URL do canal. Colar o link inteiro também funciona — ele é reduzido ao nome.

    É o nome destacado nas mensagens deste chat. Deixe vazio para destacar menções ao dono do canal; preencha com o seu nome da Twitch para ver quando falarem com você na live de outra pessoa. Cada chat pode ter um @ diferente.

    Vale só para o texto. O nome de quem escreve mantém a cor que a própria pessoa escolheu na Twitch.

    O contorno é o que mantém o nome legível sobre cenário claro, então ele não pode ser removido — só trocar de cor. O padrão é preto.

    Linhas com @seunome ganham uma marca lateral, como no chat do site. Mensagens realçadas com pontos do canal são sempre marcadas, independentemente desta opção.

    É a linha FLS Chat Overlay — desenvolvido por oFadinha.com.br acima das mensagens. Desligar devolve a faixa dela para o chat.

    Mensagens mais antigas são descartadas para não pesar.

    0 desliga — é o padrão, e o overlay fica sempre do tamanho cheio. Com qualquer outro valor, passado esse tempo sem mensagem nova o chat se recolhe para uma faixa embaixo e devolve o resto da tela para o jogo. Volta inteiro assim que alguém escreve.

    Porcentagem da altura desta janela. Num chat de 100px com 30%, sobram os 30px de baixo — as últimas mensagens. Nenhuma mensagem é apagada: só a área visível encolhe. A assinatura, quando ligada, desce junto e continua no topo da faixa.

    Todos os perfis

    Parado esse tempo com o click-through desligado, os overlays piscam em vermelho para você não esquecer que os cliques não passam para o jogo. O modo mover vale para todas as janelas ao mesmo tempo.

    Selos do chat

    Aparecem à esquerda do nome de quem escreve. São desenhados pelo próprio app, sem baixar nada — equivalentes aos da Twitch, não idênticos. O selo de assinante personalizado de cada canal não é reproduzido: assinantes aparecem sempre com a estrela roxa.

      Sobre privacidade

      O app conecta ao IRC público da Twitch como espectador anônimo (justinfan) e apenas lê. Ele não envia mensagens, não pede OAuth e não tem acesso à sua conta. Cada chat aberto é mais uma conexão anônima, nada além disso.

      Ele também não registra atalhos globais, não lê o teclado fora da própria janela e não interage com nenhum outro processo — inclusive jogos. Para reposicionar, use Ativar mover na bandeja.
